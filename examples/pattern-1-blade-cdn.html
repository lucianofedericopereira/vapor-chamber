Blade + CDN

Zero build: no npm, no Vite, one <script src>. The bundle dispatches to POST /api/vc; the cart lives on the server.

The cart count comes from the backend, not from this page. Add to cart and Clear both round-trip, and the listener renders whatever the server says the cart now is. The number is also written to localStorage, so a reload shows the last known count before the first dispatch answers.
