# vapor-chamber Laravel demo

This app was scaffolded by `examples/laravel-app/setup.sh` from the
vapor-chamber repository. It runs the library's example pages and its wire
contract checks (`node scripts/verify-contract.mjs`). The vapor-chamber
Composer package is linked by path to that repository.

Scope: this project only. No agent setup is needed: install no package
(Laravel Boost included) and run no installer, in this app or in the user's
home or system. Changes to the library belong in the vapor-chamber
repository, not here.
