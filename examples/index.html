vapor-chamber examples

Pages, no build step

  • router-demo: the router end to end (outlet, loaders, typed query params, menus).
  • feature-directives.html: v-vc-command, v-vc-payload, v-vc-optimistic, with ESM and an import map.
  • pattern-1-blade-cdn.html: a Blade-style page with the IIFE in a script tag.
  • sprinkled-blade: same origin, the cart rendered into the page by its backend, or cross-origin, the page served statically and talking to that backend.

Apps, each with its own dev server

  • vapor-sfc: npm run dev -w examples/apps/vapor-sfc, then the printed URL (default http://localhost:5173).
  • vapor-island-cart: npm run dev -w examples/apps/vapor-island-cart, then http://localhost:8889.
  • exo-astro: npm run dev -w examples/apps/exo-astro, then http://localhost:8890.

The single-file snippets in examples/snippets/ are type-checked, not run. The Laravel app is scaffolded by examples/laravel/app/setup.sh (its README).
